Use a badge to label a state (paid, overdue, building) or a kind (draft, beta, a version number) next to the thing it describes.

A badge is not a control. It cannot be pressed, toggled or removed. For a label that does any of those, use [Chip](/docs/web/components/chip).

## Usage

```tsx

```

```tsx
<Badge>New</Badge>
<Badge variant="success" dot>Paid</Badge>
<Badge variant="info" dot="pulse">Syncing</Badge>
```

## Examples

### Statuses

`success`, `info`, `warning` and `destructive` are drawn as a tint with text in the same colour, so a column of them reads as states rather than buttons. `dot="pulse"` is for a state that is still changing; use a plain `dot` once it settles.

<ComponentPreview name="badge/statuses" height={240}>

```tsx lineNumbers
import { Badge } from '@/components/panelui/badge';

const RUNS = [
  { name: 'Nightly backup', status: 'Running', variant: 'info' as const, live: true },
  { name: 'Image resize queue', status: 'Healthy', variant: 'success' as const, live: false },
  { name: 'Invoice export', status: 'Retrying', variant: 'warning' as const, live: true },
  { name: 'Search reindex', status: 'Stopped', variant: 'destructive' as const, live: false },
];

export default function BadgeStatuses() {
  return (
    <ul className="flex w-full max-w-sm flex-col divide-y text-sm">
      {RUNS.map((run) => (
        <li key={run.name} className="flex items-center justify-between gap-4 py-2.5">
          <span>{run.name}</span>
          <Badge variant={run.variant} dot={run.live ? 'pulse' : true}>
            {run.status}
          </Badge>
        </li>
      ))}
    </ul>
  );
}
```

</ComponentPreview>

## API Reference

### Badge

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `BadgeVariant` | `default` | What it means. `default` is solid, for the one thing that should be seen first; the four states are tinted in their theme colour. Default `default`. |
| `size` | `BadgeSize` | `md` | Its height and text size. Default `md`. |
| `dot` | `boolean \| 'pulse'` | — | A dot before the text in the badge's colour. `'pulse'` makes it breathe, for a state that is still changing. |

Every part also takes the props of the element it renders, and a `className`.

## Notes

### Choosing a variant

`default` is solid. Keep it for the one badge on a screen that should be seen first. `secondary` and `outline` are for kinds, the four colours for states.

### Reduced motion

The pulse does not run when the reader has asked for reduced motion. The dot stays.
