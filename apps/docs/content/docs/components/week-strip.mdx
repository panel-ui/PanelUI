Use it at the top of a schedule, where a reader picks a day and the screen below shows what is on it. It is one row, so it leaves the screen to the day's content rather than spending it on a month.

By default it shows the seven days of one week, filling the row. Pass `scroll` for a run of days in fixed-width cells that scroll sideways, for a picker that reaches a few weeks ahead.

For picking a date far from today, or a range, use [Calendar](/docs/components/calendar).

## Installation

WeekStrip ships with the library — no separate install.

```tsx
import { WeekStrip, Text } from 'panelui-native';
```

Or copy the source into your project, to own and edit it:

```bash
npx panelui-cli@latest add week-strip
```

## Usage

```tsx
const [day, setDay] = useState(() => new Date());

<WeekStrip value={day} onValueChange={setDay} weekStartsOn="auto" />
```

## Examples

### Marks

`marks` returns what each day shows: up to three `dots` in theme tones, a short `label` in their place, or a `corner` dot for a day that needs attention.

```tsx
<WeekStrip
  value={day}
  onValueChange={setDay}
  marks={(date) => (date.getDay() === 3 ? { dots: ['primary', 'success'] } : undefined)}
/>
```

### Labels instead of dots

A `label` replaces the dots, for a figure that reads better as words, such as the places left in a class.

```tsx
<WeekStrip
  value={day}
  onValueChange={setDay}
  marks={(date) => ({ label: `${freeOn(date)} free` })}
/>
```

### Disabled and faded days

`disabled` days are faded and cannot be pressed, such as a day the studio is closed. `faded` days are faded but stay pressable, such as past days a reader may still want to look back at.

```tsx
<WeekStrip
  value={day}
  onValueChange={setDay}
  disabled={(date) => date.getDay() === 0}
  faded={(date) => date < startOfToday}
/>
```

### Scrolling

`scroll` lays out `length` days from `start`, in fixed-width cells that scroll sideways. The strip opens with the selected day in view.

```tsx
<WeekStrip scroll size="sm" length={21} value={day} onValueChange={setDay} />
```

## Variants

### `size`

- `sm`
- `md` *(default)*

```tsx
<WeekStrip size="sm">…</WeekStrip>
<WeekStrip size="md">…</WeekStrip>
```

### `today`

- `true`

```tsx
<WeekStrip today>…</WeekStrip>
```

### `dim`

- `true`

```tsx
<WeekStrip dim>…</WeekStrip>
```

## Notes

### The week

`weekStartsOn` is the first day of the week, 0 for Sunday to 6 for Saturday. `auto` asks `locale`, the same way Calendar does, so `en-GB` starts on Monday. `week` picks which week is shown; it defaults to the week of `value`, or this week.

### Today

Today has a ring, and the selected day is filled. Pass `today` to set the day counted as today, for a screen that is showing a different time zone.

### Accessibility

Each day is a button. A screen reader hears the whole date in `locale`, followed by its label when it has one, and the selected day is announced as selected. Disabled days are announced as disabled.
