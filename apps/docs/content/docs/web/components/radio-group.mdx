Use a radio group for one choice out of two to about seven options, where seeing every option at once helps someone choose.

For options that each need a line of description or a price, use `RadioGroup.Card`. For options best chosen by a picture, use [Choice Cards](/docs/web/components/choice-cards). For more than about seven, use a [Select](/docs/web/components/select). For a choice that applies at once without a form, use [Tabs](/docs/web/components/tabs).

## Examples

### In a row

`orientation="horizontal"` sets the radios side by side, and the left and right arrow keys move the choice.

<ComponentPreview name="radio-group/horizontal" height={120}>

        <Radio value="yearly" />
        <Label.Text>Yearly</Label.Text>
      </Label>

### Cards

`RadioGroup.Card` puts each option in a card with the radio inside it, for options that need a line of description or a price beside the name. The whole card is the target. The default `outline` rings the chosen card.

<ComponentPreview name="radio-group/cards" height={280}>

```tsx lineNumbers
import { RadioGroup } from '@/components/panelui/radio-group';

const PLANS = [
  { value: 'hobby', title: 'Hobby', description: 'One project, community support', price: 'Free' },
  { value: 'studio', title: 'Studio', description: 'Ten projects, custom domains', price: '£12/mo' },
  { value: 'agency', title: 'Agency', description: 'Unlimited projects, client handover', price: '£39/mo' },
];

export default function RadioGroupCards() {
  return (
    <RadioGroup defaultValue="studio" aria-label="Plan" className="w-full max-w-sm">
      {PLANS.map((plan) => (
        <RadioGroup.Card key={plan.value} value={plan.value}>
          <RadioGroup.CardBody>
            <RadioGroup.CardTitle>{plan.title}</RadioGroup.CardTitle>
            <RadioGroup.CardDescription>{plan.description}</RadioGroup.CardDescription>
          </RadioGroup.CardBody>
          <RadioGroup.CardAside>{plan.price}</RadioGroup.CardAside>
        </RadioGroup.Card>
      ))}
    </RadioGroup>
  );
}
```

</ComponentPreview>

### Filled cards

`appearance="filled"` tints the chosen card in its `color`. Cards can sit in a row; a disabled one stays visible so the reader can see it is taken.

<ComponentPreview name="radio-group/cards-filled" height={200}>

```tsx lineNumbers
import { RadioGroup } from '@/components/panelui/radio-group';

const SLOTS = [
  { value: 'morning', title: 'Morning', description: '8:00 – 12:00', note: '3 left' },
  { value: 'afternoon', title: 'Afternoon', description: '12:00 – 17:00', note: '1 left' },
  { value: 'evening', title: 'Evening', description: '17:00 – 20:00', note: 'Full' },
];

export default function RadioGroupCardsFilled() {
  return (
    <RadioGroup defaultValue="morning" aria-label="Delivery slot" orientation="horizontal" className="grid w-full max-w-lg grid-cols-3">
      {SLOTS.map((slot) => (
        <RadioGroup.Card
          key={slot.value}
          value={slot.value}
          appearance="filled"
          color="success"
          disabled={slot.note === 'Full'}
          className="flex-col"
        >
          <RadioGroup.CardBody>
            <RadioGroup.CardTitle>{slot.title}</RadioGroup.CardTitle>
            <RadioGroup.CardDescription>{slot.description}</RadioGroup.CardDescription>
            <RadioGroup.CardDescription>{slot.note}</RadioGroup.CardDescription>
          </RadioGroup.CardBody>
        </RadioGroup.Card>
      ))}
    </RadioGroup>
  );
}
```

</ComponentPreview>

### Dither cards

`appearance="dither"` fills the chosen card from its far edge with an ordered dither in its colour, densest at the edge and thinning before it reaches the text. It sweeps in as the card is chosen and out as it is left.

<ComponentPreview name="radio-group/cards-dither" height={260}>

```tsx lineNumbers

const REGIONS = [
  { value: 'lhr', title: 'London', description: 'eu-west · 12 ms from you', latency: '12 ms' },
  { value: 'fra', title: 'Frankfurt', description: 'eu-central · 21 ms from you', latency: '21 ms' },
  { value: 'iad', title: 'Virginia', description: 'us-east · 78 ms from you', latency: '78 ms' },
];

export default function RadioGroupCardsDither() {
  return (
    <RadioGroup defaultValue="lhr" aria-label="Region" className="w-full max-w-sm">
      {REGIONS.map((region) => (
        <RadioGroup.Card key={region.value} value={region.value} appearance="dither" color="info">
          <RadioGroup.CardBody>
            <RadioGroup.CardTitle>{region.title}</RadioGroup.CardTitle>
            <RadioGroup.CardDescription>{region.description}</RadioGroup.CardDescription>
          </RadioGroup.CardBody>
        </RadioGroup.Card>
      ))}
    </RadioGroup>
  );
}
```

## API Reference

### RadioGroup

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `orientation` | `'vertical' \| 'horizontal'` | — | Whether the radios stack or sit in a row. Also sets which arrow keys move the choice. Default `vertical`. |
| `className` | `string` | — |  |

### RadioGroup.Radio

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `size` | `RadioSize` | `md` | Default `md`. |
| `color` | `RadioColor` | `primary` | The colour of the chosen radio. `primary` by default. |
| `label` | `string` | — | What a screen reader calls it, when there is no visible label tied to it. |
| `className` | `string` | — |  |
| `style` | `CSSProperties` | — |  |

### RadioGroup.RadioCard

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `appearance` | `RadioCardAppearance` | — | How the chosen card is marked: a ring, a tint, or a dither ramp from the far edge. The ramp draws where `RadioGroup.CardAside` would sit, so leave the aside out of a `dither` card. Default `outline`. |
| `color` | `RadioColor` | `primary` | The colour the chosen card is marked in. `primary` by default. |
| `className` | `string` | — |  |
| `style` | `CSSProperties` | — |  |

Every part also takes the props of the element it renders, and a `className`.

## Notes

### Keyboard

The group is one Tab stop. Inside it, the arrow keys move the choice to the next radio, as a native radio group does.

### Motion

The chosen radio's dot grows in with a small overshoot, and the one it leaves shrinks. With reduced motion turned on, both change at once.

### Exports

`Radio` is also exported as `RadioGroup.Item` and `RadioGroupItem`. The card parts are also exported by name, such as `RadioGroupCard` and `RadioGroupCardTitle`, for a Server Component.

### Reduced motion

The dither card's sweep and the dot's overshoot are skipped; the chosen card is filled at once.

### Server Components

`RadioGroup` is a client component. In a file that starts with `"use client"`, write its parts with a dot, as on this page. A Server Component cannot read `RadioGroup.Item` off the import, so each part is also exported by name: `RadioGroupItem` is `RadioGroup.Item`, and so on for the others.

```tsx
import { RadioGroup, RadioGroupItem, RadioGroupCard, RadioGroupCardBody, RadioGroupCardTitle, RadioGroupCardDescription, RadioGroupCardAside } from "@/components/panelui/radio-group"
```
