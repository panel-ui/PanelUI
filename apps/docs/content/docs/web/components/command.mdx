Use it for a launcher that is opened from a hotkey: search the pages of an app, its settings and its actions in one place, and run one with Enter. For a field that answers a question in rows under it, use [Command Dock](/docs/web/components/command-dock). For actions on one thing, opened from a button beside it, use a [Menu](/docs/web/components/menu).

Items are written as children. Each hides itself when it does not match what is typed: every word has to appear in its title, its `subtitle`, its `kind` or its `keywords`, in any order. A group with nothing left in it hides too, and `Command.Empty` shows when nothing is left at all. The first match is highlighted, so a few letters and Enter run it.

The default layout, `spotlight`, is the large launcher: a tall field with a mark at its start, slim rows with the kind of each at their end, and a floating footer the last rows fade out under.

Put it in a `Command.Dialog` to open it over the page with ⌘K, or Ctrl+K, or leave it in the page. Opened from its hotkey it appears at once, with no animation, because a launcher is opened many times a day.

## Composition

```tsx
<Command.Dialog>
  <Command>
    <Command.Input>
      <Command.InputAction />
    </Command.Input>
    <Command.List>
      <Command.Group>
        <Command.Item />
      </Command.Group>
      <Command.Separator />
      <Command.Loading />
      <Command.Empty />
    </Command.List>
    <Command.Footer>
      <Command.FooterButton />
      <Command.FooterAction />
      <Command.FooterDivider />
    </Command.Footer>
  </Command>
</Command.Dialog>
```

- **`Command.Dialog`** — Opens the launcher in a panel over the page, from its `hotkey` (`mod+k` by default, `null` for none) or from a `trigger`. Choosing an item closes it, unless the item has `closeOnSelect={false}`. Escape closes it too.
- **`Command.Input`** — The field. It has focus while the launcher is open, and the arrow keys and Enter work from it. `icon` replaces the magnifying glass and `prefix` puts a chip before the text, such as the page a nested list is on. Its children go at its end.
- **`Command.InputAction`** — A button at the end of the field, with its `keys` after its label, such as switching the field to asking an assistant.
- **`Command.List`** — The results, scrolling inside the launcher. In the `split` layout the preview of the highlighted item sits beside it.
- **`Command.Group`** — Items under a `heading`. It hides when none of its items match.
- **`Command.Item`** — One result: `icon`, the title as its children, a quieter `subtitle`, and at its end a `badge`, its `kind` and its `shortcut`. `onSelect` runs when it is pressed or Enter is pressed on it. `keywords` are more words to find it by, and `forceMount` keeps it whatever is typed.
- **`Command.Empty`** — Shown when no item is left.
- **`Command.Loading`** — A spinner and a line, for results still on their way.
- **`Command.Separator`** — A rule between groups.
- **`Command.Footer`** — The foot of the launcher: `lead` at its start, such as a `Command.FooterButton`, and its actions at its end. In `spotlight` it floats over the list as a round button and a pill of actions, and the last rows fade out under it; in the other layouts it is a bar.
- **`Command.FooterAction`** — An action in the footer, with its `keys` after its label. The first is usually what Enter does.
- **`Command.FooterButton`** — An icon button for the footer's start, such as one that opens a menu of settings. It needs an `aria-label`. Round in `spotlight`.
- **`Command.FooterDivider`** — A thin rule between two footer actions.
- **`Command.Keys`** — Keys drawn as key caps, for anywhere else in the launcher.

### Results from a server

`filter={false}` stops the items hiding themselves, for results already filtered elsewhere. Hold the text with `search` and `onSearchChange`, and show `Command.Loading` while the request is out.

<ComponentPreview name="command/async" height={400}>

```tsx lineNumbers
'use client';

import { PackageIcon } from 'lucide-react';
import { useEffect, useState } from 'react';
import { Command } from '@/components/panelui/command';

const PACKAGES = [
  { name: 'panelui-web', about: 'Animated React components on shadcn tokens', downloads: '18k' },
  { name: 'panelui-native', about: 'React Native components for Expo', downloads: '41k' },
  { name: 'panelui-cli', about: 'Copies components into a project', downloads: '9k' },
  { name: 'create-panelui-app', about: 'Starts an Expo app with PanelUI set up', downloads: '6k' },
  { name: 'tailwind-variants', about: 'Variant APIs for Tailwind classes', downloads: '2.1M' },
  { name: '@base-ui/react', about: 'Unstyled, accessible React primitives', downloads: '1.4M' },
];

/** Stands in for a search request that takes a moment. */
function useSearch(query: string) {
  const [state, setState] = useState({ loading: false, results: PACKAGES });
  useEffect(() => {
    setState((current) => ({ ...current, loading: true }));
    const timer = setTimeout(() => {
      const words = query.toLowerCase().split(/\s+/).filter(Boolean);
      setState({ loading: false, results: PACKAGES.filter((pkg) => words.every((word) => `${pkg.name} ${pkg.about}`.includes(word))) });
    }, 450);
    return () => clearTimeout(timer);
  }, [query]);
  return state;
}

export default function CommandAsync() {
  const [query, setQuery] = useState('');
  const { loading, results } = useSearch(query);

  return (
    <Command variant="compact" filter={false} search={query} onSearchChange={setQuery} className="max-w-lg">
      <Command.Input placeholder="Search the registry…" />
      <Command.List className="h-64">
        {loading ? (
          <Command.Loading>Searching the registry…</Command.Loading>
        ) : (
          <>
            {results.map((pkg) => (
              <Command.Item key={pkg.name} icon={<PackageIcon />} subtitle={pkg.about} kind={`${pkg.downloads}/wk`}>
                {pkg.name}
              </Command.Item>
            ))}
            <Command.Empty>No packages match “{query}”</Command.Empty>
          </>
        )}
      </Command.List>
    </Command>
  );
}
```

### Nested pages

```tsx lineNumbers
'use client';

import { ChevronRightIcon, MoonIcon, PaletteIcon, SunIcon, SunMoonIcon, TypeIcon } from 'lucide-react';
import { useState, type KeyboardEvent } from 'react';
import { Command } from '@/components/panelui/command';

const THEMES = ['Panel', 'Moon', 'Grass'];

export default function CommandPages() {
  const [page, setPage] = useState<'root' | 'theme' | 'appearance'>('root');
  const [search, setSearch] = useState('');
  const [chosen, setChosen] = useState('Panel · System');

  function open(next: typeof page) {
    setPage(next);
    setSearch('');
  }

  // Backspace in an empty field goes back a page.
  function onKeyDown(event: KeyboardEvent<HTMLInputElement>) {
    if (event.key === 'Backspace' && search === '' && page !== 'root') {
      event.preventDefault();
      open('root');
    }
  }

  return (
    <div className="flex w-full max-w-lg flex-col items-center gap-3">
      <Command variant="compact" search={search} onSearchChange={setSearch} className="w-full">
        <Command.Input
          placeholder={page === 'root' ? 'Search settings…' : 'Filter…'}
          prefix={page === 'theme' ? 'Theme' : page === 'appearance' ? 'Appearance' : undefined}
          onKeyDown={onKeyDown}
        />
        <Command.List className="h-52">
          {page === 'root' ? (
            <Command.Group heading="Settings">
              <Command.Item icon={<PaletteIcon />} closeOnSelect={false} kind={<ChevronRightIcon />} onSelect={() => open('theme')}>
                Change theme…
              </Command.Item>
              <Command.Item icon={<SunMoonIcon />} closeOnSelect={false} kind={<ChevronRightIcon />} onSelect={() => open('appearance')}>
                Change appearance…
              </Command.Item>
              <Command.Item icon={<TypeIcon />} subtitle="16px">
                Text size
              </Command.Item>
            </Command.Group>
          ) : null}
          {page === 'theme' ? (
            <Command.Group heading="Themes">
              {THEMES.map((theme) => (
                <Command.Item
                  key={theme}
                  icon={<PaletteIcon />}
                  onSelect={() => {
                    setChosen((current) => `${theme} · ${current.split(' · ')[1]}`);
                    open('root');
                  }}
                >
                  {theme}
                </Command.Item>
              ))}
            </Command.Group>
          ) : null}
          {page === 'appearance' ? (
            <Command.Group heading="Appearance">
              {[
                { name: 'Light', icon: <SunIcon /> },
                { name: 'Dark', icon: <MoonIcon /> },
                { name: 'System', icon: <SunMoonIcon /> },
              ].map((option) => (
                <Command.Item
                  key={option.name}
                  icon={option.icon}
                  onSelect={() => {
                    setChosen((current) => `${current.split(' · ')[0]} · ${option.name}`);
                    open('root');
                  }}
                >
                  {option.name}
                </Command.Item>
              ))}
            </Command.Group>
          ) : null}
          <Command.Empty />
        </Command.List>
        <Command.Footer lead={page === 'root' ? 'Settings' : 'Backspace to go back'} />
      </Command>
      <p className="text-sm text-muted-foreground">Now: {chosen}</p>
    </div>
  );
}
```

## Notes

### Keyboard

The arrow keys move the highlight, Enter runs the highlighted item, and Escape closes a dialog. In the `grid` layout Left and Right move across a row. The hotkey opens and closes the dialog from anywhere on the page.

### Choosing a hotkey

A page never receives the keys a browser keeps for itself, such as ⌘T, ⌘W or ⌘1 to ⌘9. ⌘K and Ctrl+K are free to use and are what most launchers use. With more than one `Command.Dialog` on a page, or a search of your own already on ⌘K, give only one of them the hotkey and pass `hotkey={null}` to the rest.

### Accessibility

The field is a combobox and the results are a listbox, so a screen reader announces the highlighted item as the arrow keys move. The dialog is named by its `label`, `Command menu` by default. Shortcuts drawn by `shortcut` and `Command.Keys` are only shown; handle the keys where the action lives.

### Server Components

`Command` is a client component. In a file that starts with `"use client"`, write its parts with a dot, as on this page. A Server Component cannot read `Command.Dialog` off the import, so each part is also exported by name: `CommandDialog` is `Command.Dialog`, and so on for the others.

```tsx
import { Command, CommandDialog, CommandInput, CommandInputAction, CommandList, CommandGroup, CommandItem, CommandEmpty, CommandLoading, CommandSeparator, CommandFooter, CommandFooterAction, CommandFooterButton, CommandFooterDivider, CommandKeys } from "@/components/panelui/command"
```
